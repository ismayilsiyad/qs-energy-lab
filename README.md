# Quanskill Energy Lab - hosted dashboard

The exact Streamlit dashboard from the Quanskill Energy Lab notebook, hosted permanently here. A wood-processing plant, 2 years of meter sheets, rebuilt from the raw registers.

- Data: downloaded from the public data pack on first start (gold tables only).
- AI chat and page insights: routed through the class AI endpoint; no Azure key in this repo.
- Runs on Streamlit Community Cloud.
